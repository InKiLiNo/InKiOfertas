# 01. Objetivo y alcance — Aplicación de ofertas THEGSA

## Objetivo
Aplicación sencilla para configurar depósitos cilíndricos verticales de THEGSA y generar el texto técnico de sus ofertas, editable y exportable a la plantilla Word actual conservando su formato.

## Alcance V1
Solo dos modelos:
- Depósito vertical con fondos Klopper y patas.
- Depósito vertical con fondos Klopper y cartelas.

Incluye datos generales de oferta, geometría básica, materiales, soportación, orejetas, soporte de placa, aislamiento, acabados, condiciones de diseño, conexiones, accesorios, texto técnico editable y exportación Word.

## Fuera de V1
Se posponen costes, precios, pesos, horas, escandallos, otros equipos y depósitos horizontales, camisas, media caña, serpentines, agitadores y cálculos avanzados de diseño.

## Principios
- Partir de plantillas preconfiguradas, no de formularios vacíos.
- Valores habituales por defecto, siempre modificables.
- Evitar duplicar datos.
- Separar datos técnicos estructurados del texto de oferta.
- No sobrescribir cambios manuales del texto sin aviso.
- Interfaz simple y rápida.

El árbol real de escandallos de THEGSA será referencia para futuras ampliaciones, no el catálogo de V1.
