# 03. Generación de ofertas

## Datos generales
- Número de oferta (obligatorio).
- Revisión (0 por defecto).
- Cliente (obligatorio).
- Fecha (automática).
- Proyecto/referencia (opcional).
- Descripción del equipo (obligatoria).
- Cantidad (1 por defecto).

## Texto técnico
Generar un texto profesional a partir de la configuración, con este orden:
1. Descripción y modelo de construcción.
2. Geometría y dimensiones.
3. Materiales.
4. Conexiones.
5. Accesorios.
6. Aislamiento, solo si aplica.
7. Acabados.
8. Condiciones de diseño y norma.

Omitir apartados que no apliquen. Conservar designaciones, unidades y normas seleccionadas.

## Edición
El texto generado será editable libremente. Editar el texto no modifica los datos técnicos. Guardar configuración y texto final por separado. Si se regenera después de editar, advertir y no perder cambios silenciosamente; preferiblemente crear una nueva versión para comparar.

## Word
Usar la plantilla Word actual de THEGSA y conservar estilos, encabezados, pies, tablas y distribución. Rellenar únicamente los campos/bloques previstos. El documento resultante será editable en Word.

**Pendiente imprescindible:** recibir la plantilla .docx actual y una oferta completada representativa. Inspeccionar su estructura antes de decidir cómo rellenarla; no asumir marcadores.

Nombre de archivo: pendiente de confirmar. Propuesta: `OF-[Número] Rev.[Revisión] - [Cliente] - [Descripción].docx`.
